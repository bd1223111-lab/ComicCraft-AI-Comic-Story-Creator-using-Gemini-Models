ComicCraft – AI Comic Story Creator using Gemini Models

Phase 2 – Requirement Analysis

1. Functional Requirements

• User should be able to enter a comic story topic.
• User should be able to select a genre.
• User should provide character details.
• System should send the information to Gemini.
• Gemini should generate a comic story.
• System should generate scenes for different comic panels.
• System should generate dialogues.
• System should provide image-generation prompts.

2. Input Requirements

• Story topic
• Genre
• Main character
• Supporting characters
• Number of comic panels
• Story mood
• Target audience

3. Output Requirements

The system should generate:

• Comic title
• Story summary
• Character descriptions
• Panel descriptions
• Scene descriptions
• Character dialogues
• Narration
• Image prompts

4. Software Requirements

• Python
• Google Colab
• Google GenAI library
• Gemini API
• GitHub

5. Hardware Requirements

• Computer or laptop
• Minimum 4 GB RAM
• Internet connection

6. Non-Functional Requirements

• Simple user interface
• Fast response
• Easy-to-understand output
• Reliable AI response
• Secure API-key handling

7. Expected Result

The system should generate a structured comic story based on the
information provided by the user.
