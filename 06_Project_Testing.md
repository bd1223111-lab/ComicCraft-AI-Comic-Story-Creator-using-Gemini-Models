ComicCraft – AI Comic Story Creator using Gemini Models

Phase 6 – Project Testing

1. Testing Objective

The objective of testing is to verify that ComicCraft correctly accepts
user inputs, communicates with Gemini, and generates a structured comic
story.

2. Test Cases

Test Case 1
Input: Valid comic topic
Expected Result: Comic story should be generated.

Test Case 2
Input: Different genre
Expected Result: Story should match the selected genre.

Test Case 3
Input: Character details
Expected Result: Characters should appear appropriately in the story.

Test Case 4
Input: Multiple panels
Expected Result: Story should be divided into the requested panels.

Test Case 5
Input: Empty topic
Expected Result: User should be asked to provide a topic.

Test Case 6
Input: Valid Gemini request
Expected Result: Gemini should return a response.

Test Case 7
Output display
Expected Result: Story, panels, dialogues, and prompts should be
displayed clearly.

3. Testing Process

• Enter comic requirements.
• Submit the request.
• Send the prompt to Gemini.
• Check the generated story.
• Verify characters and dialogues.
• Verify panel descriptions.
• Check image prompts.
• Check for errors.

4. Expected Testing Outcome

ComicCraft should generate a structured and understandable comic story
based on the user's requirements.
