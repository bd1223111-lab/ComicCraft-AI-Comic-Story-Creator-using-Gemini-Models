ComicCraft – AI Comic Story Creator using Gemini Models

Phase 3 – Project Design

1. System Architecture

User
↓
ComicCraft Application
↓
User Input Processing
↓
Gemini AI Model
↓
Story Generation
↓
Comic Panel Generation
↓
Dialogue and Image Prompts
↓
Final Comic Output

2. Main Modules

Module 1 – User Input Module

Collects the topic, genre, characters, mood, and number of panels.

Module 2 – Prompt Generation Module

Converts user information into a structured prompt for Gemini.

Module 3 – AI Story Generation Module

Sends the prompt to Gemini and receives the generated comic story.

Module 4 – Comic Panel Module

Organizes the story into individual comic panels.

Module 5 – Dialogue Module

Generates suitable character dialogues and narration.

Module 6 – Output Module

Displays the complete comic story in a structured format.

3. Data Flow

User Input
→ Prompt Creation
→ Gemini Processing
→ Story Generation
→ Panel Generation
→ Final Output

4. Design Goal

The application is designed to provide a simple and creative way to
generate comic stories using Generative AI.
